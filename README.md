# 灵脉回响 · Echoes of the Living Land

云南生态与神话的桌面交互作品。保留第一版绘画长卷界面，点击按钮进入三个独立的实时三维微缩岛屿，也可随时返回绘画界面。

## 三座岛屿

- 雪岭源流：滇金丝猴、雪山、针叶林与动态飘雪。
- 古林象道：亚洲象群、雨林植被与溪流廊道。
- 金湖羽梦：绿孔雀、金湖、水纹与完成剧情后的初雨。

岛屿有封闭岩体、土壤层和岩层纹理。支持旋转、缩放、植物生长与时间回溯。图鉴收录三种动物、六组植物概念素材及生态与神话来源。

## 本地运行

Node.js 22 或更新版本，无需安装运行依赖。执行 `npm start` 后打开 http://127.0.0.1:4186/ 。不要直接双击 HTML，模块与模型资源需要 HTTP 服务。

## 操作

点击“进入微缩世界”进入 3D。拖动环游，滚轮缩放，双击归位。“生长”会先展示一簇植物，随后可点击或拖动空地种植，约 3 秒舒展成形。R 按住回溯，F 全屏，H 纯净展示，1/2/3 切岛，空格暂停。点击声音按钮开启合成声景。

每章三个剧情节点，依次完成雪岭、象道、金湖。剧情进度保存在浏览器；创作手记中可重置。生长与回溯历史在页面会话内按岛保存，刷新后不持久化。

## 文件

- `dist/`：完整静态作品；`docs/` 是 GitHub Pages 发布副本。
- `dist/app.js`：绘画/三维切换、剧情、图鉴和交互。
- `dist/world.js`：第一版绘画长卷渲染。
- `dist/island.js`：独立三岛、模型加载、实心底座、生长和降雪。
- `dist/aftertouch-world.js`：适配的 Aftertouch World 场景与模拟。
- `dist/data.js`：物种说明、素材映射和资料出处。
- `model-source/`：Blender 源文件及模型生成脚本。浏览器直接加载已导出的 GLB，无需 Blender。
- `references/`：留存的上游源文件和许可。
- `validation/`：本地浏览器验收结果。

## 技术与创作边界

直接使用并改造 [Aftertouch](https://github.com/NickChaps/aftertouch) 的 World、地形、草地、粒子、生长事件、时间回溯和声音代码。渲染使用 Three.js 0.180.0。保留 MIT 许可，见 `dist/licenses.txt` 和 `dist/vendor/THREE-LICENSE.txt`。字体 Noto Serif SC 使用 OFL。创作者提供的图像不自动适用软件的 MIT 许可。

动物为程序化建模的风格化三维雕塑，包含毛发、面部、象鼻褶皱和多层尾羽；不是写实生态仿真或完整骨骼动画。地理连接、礼饰、发光符号和唤雨属于艺术表达，生态与神话来源分别标注。

## 验证与发布

`npm run check` 检查 JavaScript 语法；`npm run prepare-pages` 同步静态资源。GitHub Pages 使用 main 分支 `/docs`。

本地浏览器验收覆盖 30 项主要流程；另行验证了绘画入口和返回、三岛显著生长、不透明底座及仅第一岛飘雪。测试帧率不是对其他设备的性能保证。界面按电脑演示设计。
